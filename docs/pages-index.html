IELTS 学习工具

三个离线可用、单文件、可打印的雅思学习页面：写作范文库、口语 Part 2 素材库与阅读互动解析。CSS、脚本与数据全部内联，下载后双击即可打开。

  • IELTS Writing 范文库

    Task 1 × Task 2

    • 13 类写作题型：Task 1 八种图表、Task 2 五种提问方式
    • 真实考场题目，原创 7.5 分范文
    • 逐段解析：任务回应、结构与逻辑、词汇与语法、可迁移句式
    • 点击解析关键词，定位范文原句并精确高亮
    打开范文库

  • IELTS Reading 互动解析

    阅读试卷 · 单文件 HTML

    • 试卷照片转单文件 HTML，逐字还原文章与题目
    • 每题中文解析，默认展开，附「原文回顾」证据句
    • 点击解析关键词，跳回原文并精确高亮证据句
    • 支持打印与导出 PDF
    打开阅读示例

  • IELTS Speaking Part 2 素材库

    口语第二题 · 素材与范例

    • 按话题整理的 Part 2 素材与可复用表达
    • 单一 Markdown 源文件，同源导出 HTML 与 PDF
    • 可直接打印成纸质素材卡
    打开口语素材库

写作题库来自 IELTS Buddy 公开考场回忆接口，共 3,743 条记录；范文与解析为原创教学示例，非官方标准答案。

页面可离线使用，Ctrl/Cmd + P 可导出 PDF。
